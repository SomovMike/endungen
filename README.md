# Endungen

Тренажёр окончаний немецких прилагательных (Nom, Akk, Dat) для телефона.

**Играть:** https://somovmike.github.io/endungen/

- **Спринт · 60 с** — случайные фразы, сколько верных окончаний успеешь. Ошибка = −3 с.
- **Обучение** — разбор каждой ошибки, слабые клетки таблицы выпадают чаще.

На телефоне можно добавить на главный экран (Поделиться → На экран «Домой»), тогда работает и без интернета. Рекорды хранятся в браузере.

## Разработка

`app.html` — единственный исходник. `python3 build.py` собирает сайт в `docs/` (его раздаёт GitHub Pages). Для иконок нужен `rsvg-convert` (`brew install librsvg`).
